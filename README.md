# Магазин косметики

Flutter Web, практические работы 2 и 3. Реализованы каталог, связанные сущности,
формы с валидацией и постоянное хранилище браузера.

## Запуск

```bash
flutter pub get
flutter run -d chrome --web-hostname 127.0.0.1 --web-port 5555
```

Если автоматический запуск браузера недоступен:

```bash
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 5555
```

Открыть http://127.0.0.1:5555/products. Для размещения `build/web` сервер должен
отдавать `index.html` для маршрутов приложения (SPA fallback).

## Практика 3

Пять разделов: **товары, бренды, категории, поставщики, покупатели**.
У покупателя есть вложенная карта лояльности. Во всех разделах доступны список,
карточка, создание (кнопка «+» у заголовка), редактирование, логическое и физическое
удаление, восстановление, поиск, фильтр, сортировка, выделение и пагинация 10/25/50.

- У товара один бренд и один поставщик (многие к одному), несколько категорий
  (многие ко многим). У поставщика выбираются поставляемые бренды.
- После выбора поставщика в форме товара доступны только его бренды. Несовместимый
  ранее выбранный бренд сбрасывается. Связи также проверяются в репозитории.
- У покупателя ровно одна карта лояльности, редактируемая в той же форме.
- Общая форма `EntityEditor` строится из `FieldSpec`: пять сущностей используют
  одинаковые разметку, отправку и показ ошибок. Создание/изменение — один экран.
- Ошибки обязательности, длины, чисел, цены, почты, телефона, дат и выбора связей
  выводятся под полями. Цена хранится целым количеством копеек.
- Уникальны артикул товара, почта покупателя и номер карты (без учёта регистра,
  с исключением самой редактируемой записи). Удалённые записи тоже резервируют значения.
- Удаление используемого поставщика, бренда или категории запрещено с показом
  числа зависимых записей. Групповое удаление проверяется целиком до изменения.
- `PopScope` и `go_router.onExit` защищают несохранённые изменения при навигации.
  На web `beforeunload` дополнительно просит браузер предупредить о закрытии/обновлении
  вкладки; вид и показ этого системного диалога определяются браузером.
- `shared_preferences` сохраняет JSON в localStorage после каждой успешной операции.
  Используется ключ `cosmetics_shop_v2`, версия 2. Старые/повреждённые данные
  сохраняются в резервной копии; пользователь видит сообщение о восстановлении.
- Изменения в памяти подтверждаются только после успешной записи. Сохранения в
  одной вкладке выполняются последовательно. Данные сохраняются для конкретного
  адреса и порта; живой обмен изменениями между одновременно открытыми вкладками
  не реализован. Сервер подключается в последующих работах.

Бренды реальные: Bioderma, Garnier, COSRX, Maybelline New York, NIVEA,
L’Oréal Paris, CeraVe, La Roche-Posay. Ассортимент и цены демонстрационные;
поставщики и покупатели вымышлены. При первом запуске: 30 товаров, 8 брендов,
5 категорий, 3 поставщика, 12 покупателей с картами.

## Практика 2 сохранена

Provider / ChangeNotifier, `EntityTable<T>`, адаптивные карточки при ширине <600 px,
параметры списка в адресе, история браузера и задержка поиска 350 мс. Изменение
условий сбрасывает страницу и выделение. После удаления последней записи номер
страницы корректируется; устаревший результат не отменяет новую навигацию.

Для демонстрации ошибки загрузки: меню «Проверка состояний» → «Показать учебную
ошибку» → «Повторить». Поиск `несуществующийтовар` показывает пустой результат.

Ошибка `deleteMany` из задания: выражение `b[i].isDeleted` обращалось к одной
сущности как к массиву, причём индекс ещё вычислялся. Правильно: `b.isDeleted`.

## Проверка

```bash
flutter analyze
flutter test
flutter build web --release
```

Тесты проверяют репозитории, формы, уникальность, связи, сохранение/восстановление,
переходы, пагинацию и мобильную вёрстку.
